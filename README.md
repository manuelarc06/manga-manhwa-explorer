# manga-manhwa-explorer
Manga & Manhwa Explorer is a web application that helps users discover, search, and explore manga and manhwa titles in one place.

# Features
Search manga and manhwa by title.
Explore titles by genre.
View manga details, ratings, and available chapter information.
Save favorite titles using LocalStorage.
Discover new titles with a random selection feature.

# Technologies
HTML
CSS
Vanilla JavaScript
External APIs
LocalStorage

# Purpose
This project was developed for the WDD 330 final project to demonstrate skills in API integration, JSON data manipulation, dynamic content generation, responsive web design, and JavaScript programming.
